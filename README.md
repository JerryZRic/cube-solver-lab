# Cube Lab · 魔方求解实验室

一个独立、中文、浏览器内运行的 3×3 魔方研究原型。以 **Three.js + TypeScript + Vite** 实现，使用 cubejs 的 Kociemba 两阶段算法求解当前合法状态。

## 可以试什么

- 鼠标/触控拖动观察，滚轮/双指缩放；一键恢复观察视角。
- U/R/F/D/L/B 六面顺逆时针旋转；键盘对应字母、Shift 反向。
- 开启“点按转面”后，点按某个色块可旋转对应面；拖动仍为观察视角。
- 20 步合法随机转动打乱、随时复原；六面展开图实时同步。
- **从当前状态求解**，包括打乱后继续手动转动的状态。不是倒放打乱记录。
- 显示完整解法；播放、暂停、前后单步、0.5×–3× 调速。

## 本地开发

要求 Node.js 22.12+（本次验证环境为 24）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`dist/` 为静态发布目录。无需后端 API、密钥或云端求解服务，魔方状态不离开浏览器；页面刷新会清空状态。

## 技术选择

本原型的重点是离散魔方状态、求解算法和精确转面动画，而非场景编辑或多人游戏。Three.js 提供直接的渲染控制，TypeScript 状态模型与 UI/算法可以独立测试；PlayCanvas 更适合需要可视化场景编辑及较完整游戏工作流的后续项目。本阶段不引入第二套引擎。

- `src/cube.ts`：整数坐标/贴纸法线，54 面片序列化；不会把动画浮点值写回逻辑状态。
- `src/view.ts`：Three.js 圆角方块、贴纸、OrbitControls；每次动画结束重建到精确状态。
- `src/solver.worker.ts`：Web Worker 初始化并执行求解；验证排列、翻转、扭转、奇偶及最终解法。
- `src/main.ts`：输入互斥、播放控制、请求 ID 与世代取消；复原不会被迟到的动画/求解覆盖。
- `tests/`：转动不变量、cubejs 对照、随机打乱求解及非法状态拒绝。

## 研究范围与限制

- 只支持标准三阶魔方，由合法转动生成状态；不提供拍照识别、手工颜色录入或任意阶数。
- 打乱是随机合法转动序列，**不是 WCA 比赛用的随机状态打乱**。
- 两阶段算法返回可行解，**不保证最少步数**，也不是逐层教学解法。
- 第一次求解需要构建查找表，通常需数秒；工作在线程中执行，不阻塞 3D 视图。45 秒超时后可重试。
- 暂停会完成当前这一转，随后停下。复原则立即取消当前动画/回放。
- 需要现代浏览器与 WebGL；不可用时提供二维状态/求解降级，未进行所有设备与 Safari 的兼容性认证。
- 原型为独立个人试用项目，不部署到 timewish.net，不涉及其他游戏项目或 Windows 打包。
